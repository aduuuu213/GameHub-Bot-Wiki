# Deepseek 标题与档案内容改写

打开 **任务控制 → Deepseek**。标题和内容分开设置，各自选一种方式：

- **大模型**：按提示词改写，需要 API Key
- **自定义脚本**：按 Python 脚本改写，不需要 API Key。脚本可以用大模型帮你写

改完后点 **保存**。到 **任务控制 → 任务编排**，把「标题优化」「档案内容优化」选成 **跟随全局设置** 或 **强制开启**。选 **强制关闭** 则该账号不改写。

## 填写 API Key

只用自定义脚本时，跳过本节。

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com)，登录。
2. 进入 **API keys**，新建密钥并复制。密钥只完整显示一次。
3. 回到 **任务控制 → Deepseek → 设置**。
4. 粘贴到 **API Key**。**API Base** 保持 `https://api.deepseek.com`，**模型** 保持 `deepseek-chat`。
5. 点 **连接测试**。成功后再点 **保存**。

## 用大模型改写

1. 打开 **标题** 或 **内容**。
2. **改写引擎** 选 **大模型**。
3. 打开 **标题优化** 或 **档案内容优化**。
4. **禁止词** 多个词之间用一个空格分开，没有就留空。
5. 提示词留空即使用默认提示词。要在默认内容上修改：点 **加载默认提示词**，改完后保留 `{titles}` 和 `{forbidden_words}`。
6. 在 **快速测试** 里确认结果：
   - 标题：输入原标题，可选一个游戏，点 **测试**。
   - 内容：粘贴描述，或填写档案号后点 **加载**，再点 **测试**。
7. 点 **保存**。


## 让大模型写自定义脚本

1. 打开 **标题** 或 **内容**。
2. **改写引擎** 选 **自定义脚本**。
3. 点 **复制系统提示词**。标题和内容各复制各的。
4. 新开一个对话（DeepSeek、ChatGPT 或其他模型都可以），把提示词整段粘贴进去。
5. 在提示词后面写上你要的改法，例如：

```
补充要求：
- 不要改原标题的文字、数量和词序
- 在标题开头随机插入一个表情，从 ✨、⭐、🔥、🎮 里选
- 在标题末尾随机插入一个字符，从 ★、♪、※ 里选
- 大约一半的情况，在标题中间再随机插入一个 ·
- 每次调用结果可以不同，总长度仍不超过 50
```

6. 发送。只要回复里的 Python 代码。
7. 代码如果包在 ` ``` ` 里，去掉 ` ``` ` 和前后说明，只留代码。
8. 粘贴到页面的脚本框，点 **格式化**。
9. 用一条真实标题或描述点 **测试**。结果不对，或页面报错，把报错原文贴回对话，让它重写后再测。
10. 点 **保存**，再到任务编排里打开对应开关。

点 **加载默认脚本** 只能对照着看写法，不能保存后用于正式出品。正式使用前换成自己的脚本，再 **测试**、**保存**。

## 使用时注意

- 测试用的是当前页面上的内容。出品只用已经点过 **保存** 的配置。
- 标题改写失败时，该子任务会被关闭。到任务编排查看原因，修好后重新打开。
- 页面提示未配置 API Key、但你只用脚本：把改写引擎改成 **自定义脚本** 并保存。
