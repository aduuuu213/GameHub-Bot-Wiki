# Deepseek 标题与档案内容改写

## 功能介绍

出品时如果多条商品标题高度相似，首页容易被平台当成重复标题处理，排名会受影响。Deepseek 页用来在**不改变商品核心属性**的前提下，把标题和档案描述改得彼此不同。

页面在 **任务控制 → Deepseek**，分三个页签：

| 页签 | 作用 |
|------|------|
| 标题 | 出品时改写商品标题 |
| 内容 | 出品时改写档案描述；档案编辑页也可手动优化描述 |
| 设置 | 填写 DeepSeek API Key、接口地址和模型 |

标题和内容各自独立，都可以在两种改写引擎里选一种：

- **大模型**：把原文交给 DeepSeek，按提示词改写。需要 API Key，按调用计费，措辞更灵活。
- **自定义脚本**：在本机执行一段 Python，按你写死的规则改写。不调用大模型，不需要 API Key，结果更稳定、可重复。

两种引擎可以只开其中一个。标题用脚本、内容用大模型也可以。当前选中的引擎才参与出品；另一套提示词或脚本会一起保存，切换回来仍然在。

改写只动文字，不改价格、库存、图片和档案号。标题结果最长 50 个字符，档案内容最长 1999 个字符，超出部分由系统截断。

## 什么时候会真正改写

配置要同时满足「全局或编排开关已打开」和「对应引擎已保存」。快速测试用的是页面上当前内容，**还没点保存的修改不会进入出品**。

### 全局开关

在 Deepseek 页：

- **标题优化**：打开后，出品可以改写标题。
- **档案内容优化**：打开后，出品可以改写描述，商品档案的新增/编辑表单里会出现 **Deepseek 优化描述**。

禁止词在同一行填写，多个词之间用**一个空格**分开。改写时不要往结果里新加这些词；原文里已经有的词保持原样。

### 任务编排优先于全局

打开 **任务控制 → 任务编排**，在「标题 / 档案内容优化」里分别设置：

| 选项 | 含义 |
|------|------|
| 跟随全局设置 | 以 Deepseek 页的开关为准 |
| 强制开启 | 本编排一定改写，即使全局是关的 |
| 强制关闭 | 本编排不改写，即使全局是开的 |

编排里的选择盖过全局开关。只想给部分账号试跑时，把这些账号的编排设成「强制开启」，其余保持「跟随全局设置」且全局关闭。

### 出品时怎么接上

开关为开时，每次新上架会改写一次：

1. 读取档案里的原始标题或描述。
2. 按该页签当前保存的引擎执行。
3. 大模型标题改写会带上近期同类商品标题，用来避开雷同。这些参考标题来自该游戏分类近 30 分钟首页采集，最多 10 条，并排除当前店铺自己的商品。
4. 用改写结果去出品。档案原文不会被改掉。

失败时两边处理不同：

- **标题失败**（没配 Key、脚本报错、脚本为空、接口超时等）：关闭这条子任务，并中止本次上架。到任务编排里看状态说明，修配置后重新打开子任务。
- **档案内容失败**，或结果里出现 `http` / `HTTP`：本次出品改回原始描述，子任务继续。

商品档案里的 **Deepseek 优化描述** 只在「档案内容优化」全局开关打开后出现。它使用已保存的内容引擎、提示词、禁止词和脚本，优化结果写进描述框，需要再点档案的保存才会落库。这里失败会直接提示错误，不会悄悄改档案。

## 获取并填写 DeepSeek API Key

只用自定义脚本时可以跳过本节。标题或内容任一页签选了「大模型」，就必须配置 Key。未配置时，页顶会提示大模型改写无法调用。

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com)，注册并登录。
2. 进入 **API keys**，新建一把密钥。密钥一般以 `sk-` 开头，创建后只完整显示一次，请立刻复制保存。
3. 账户需要有可用余额，调用按量扣费。余额不足时，连接测试和出品都会失败。
4. 回到系统 **任务控制 → Deepseek → 设置**：
   - **API Key**：粘贴刚才的密钥。系统不预置密钥。
   - **API Base**：保持 `https://api.deepseek.com`。只有官方要求更换地址时才改。
   - **模型**：保持 `deepseek-chat`。
5. 先点 **连接测试**。成功会显示「连接成功」和实际使用的模型。测试用的是输入框里的内容，通过后再点 **保存**。出品只认已保存的 Key。

Key 填错、Base 不可达、模型名无效或余额不足时，连接测试会返回失败原因。标题如果开着大模型，这类错误在出品时会关掉对应子任务。

## 方式一：大模型优化

页签里把 **改写引擎** 选成 **大模型**，下面出现提示词输入框。

### 默认提示词怎么用

提示词留空时，出品和测试都使用系统内置模板。想在默认模板上修改时：

1. 点 **加载默认提示词**。这一步会覆盖输入框里现有内容，包括还没保存的修改。
2. 按自己的品类改措辞，保留需要的占位符。
3. 点 **保存**。

标题模板里的占位符：

| 占位符 | 替换成 |
|--------|--------|
| `{titles}` | 近期同类参考标题，一行一条。测试时要先在「快速测试」里选游戏才会有内容 |
| `{forbidden_words}` | 当前禁止词。没填时使用系统内置的一组常见误导词 |

内容模板只有 `{forbidden_words}`。不要删掉仍要生效的占位符，否则模型看不到参考标题或禁止词。

### 标题默认提示词

```
# 商品标题优化任务

## 任务要求
1.保留核心信息：必须完整保留原标题中的数量、型号、关键属性等核心要素，不得增删或修改任何文字内容。
2.数值区间处理：若原标题包含数值区间（如价格范围、数量范围等），必须同时保留最小值与最大值，禁止删除任一数值端点。允许使用标准数值缩写单位（如：個、十、百、千、万）进行合理简化。
3.调整语句顺序：允许自由调整标题中词语和短语的顺序，以实现差异化。
4.修改间隔符：可以根据需要调整分隔符（如空格、逗号、斜杠、加号等）的使用，以优化排版和可读性。
5.任意使用Emoji表情：可根据标题内容和目标受众，自由添加常用Emoji表情，以增强吸引力。
6.严禁内容重复：标题需与其他商家有明显区别，避免与参考内容高度相似。
7.字数限制：总字符数（含空格和表情）严格控制在50个以内。
7.禁止误导信息：不得添加任何可能改变商品属性或功能描述的词语（如{forbidden_words}等）。若原标题已包含此类词语，则需保留。

## 参考示例（仅供差异化参考，请勿直接模仿）
{titles}

## 输出要求
- 直接输出优化后的商品标题
- 无需任何其他说明
```

模型收到的用户消息是「待优化标题：」加档案原标题。回复应只有一行标题，不要解释。

### 档案内容默认提示词

```
# 商品档案内容优化任务

## 任务要求
1.保留核心信息：必须完整保留原描述中的数量、型号、关键属性、账号状态等核心要素，不得增删或修改任何会改变商品属性的文字内容。
2.优化可读性：允许调整语句顺序、分段与标点，使描述更清晰、更易阅读。
3.禁止添加链接：不得输出任何 URL、域名或含 http/https 的文本。
4.禁止误导信息：不得添加任何可能改变商品属性或功能描述的词语（如{forbidden_words}等）。若原文已包含此类词语，则需保留。
5.字数限制：总字符数严格控制在1999个以内。

## 输出要求
- 直接输出优化后的商品档案内容
- 无需任何其他说明
```

内容结果里一旦出现 `http` 或 `HTTP`，出品会丢弃这次结果并使用原始描述。

### 自己改提示词时建议写清的事

- 必须保留的信息：数量、型号、数值区间的两端、关键属性。
- 允许的改动：词序、分隔符、少量 emoji。
- 禁止的改动：新增卖点、改价格、改账号状态、加联系方式和链接。
- 输出形式：只输出改写结果，不要加「优化后：」之类的前后缀。标题要求单行，且 50 字以内。

### 快速测试

测试读的是当前输入框，可以先测再保存。

标题：

1. 在快速测试里输入一条真实档案标题。
2. 可选一个游戏。选中后会拉取该分类的参考标题，并代入 `{titles}`。不选游戏时参考列表为空，看不出和别人的差异。
3. 点 **预览提示词**，确认禁止词和参考标题已经嵌进模板。
4. 点 **测试**。下方同时显示原文和结果。

内容：

1. 直接粘贴描述，或输入档案号后点 **加载**。
2. 需要时先 **预览提示词**。
3. 点 **测试**，左右对照原文和结果。

确认结果可用后，回到表单顶部点 **保存**。

## 方式二：自定义脚本

把 **改写引擎** 选成 **自定义脚本**。下面的编辑器只执行 Python，不请求 DeepSeek。脚本引擎不使用 API Key。

脚本在隔离环境里运行，大约 10 秒超时，源码不超过 50KB。编辑器里 **格式化**（或 `Ctrl+Alt+L`）只调整缩进和排版，不改变逻辑。

### 必须实现的函数

标题：

```python
def generate_title(title: str, others: list, extra: dict) -> str:
    ...
```

| 参数 | 含义 |
|------|------|
| `title` | 档案原始标题 |
| `others` | 近期同类标题列表，可能是空列表。测试时只有选了游戏才会有数据 |
| `extra` | 附加数据。出品时可能有 `platform`（`gametrade` 或 `gameclub`）、`gt_abbreviation`、`forbidden_words`、`did` |

内容：

```python
def generate_content(content: str, extra: dict) -> str:
    ...
```

| 参数 | 含义 |
|------|------|
| `content` | 档案原始描述 |
| `extra` | 可能有 `platform`、`forbidden_words`、`did` |

函数必须返回字符串。空原文应原样返回。标题尽量不超过 50 字，内容不超过 1999 字。内容返回值里不能出现 `http` 或 `HTTP`。

### 默认脚本做什么

点 **加载默认脚本** 会覆盖编辑器，加载后仍要点 **保存**。

标题默认脚本保留第一段，将其余用空格分开的片段打乱，并有一定概率在末尾加一个 emoji，最后截到 50 字。内容默认脚本在原文随机位置插入一个平假名，用来和原文形成轻微差别。默认脚本适合先跑通流程；正式使用前建议按品类收紧规则，再用真实标题测试。

### 脚本允许和禁止的写法

允许使用这些已内置模块：`random`、`re`、`json`、`math`、`unicodedata`、`itertools`、`collections`、`string`、`datetime`。可以写 `import`，也可以直接用。

下面的写法会被拒绝，测试和出品都会失败：

- 导入其他模块，或安装第三方包
- `os`、`sys`、`subprocess`、`socket`、`pathlib`、读写文件、访问网络
- `eval`、`exec`、`open`、`compile`、`getattr`、`setattr`
- 访问 `__` 开头的属性，使用 `global`、`nonlocal`、`async`、`yield`
- `classmethod`、`staticmethod`、`property`、`super`、`type`、`object`
- 类型写成 `list[str]` 这种形式。注解只用 `list`、`dict`、`str`
- `print`

脚本里不要再调用大模型。差异化用词序、分隔符、`random` 和少量 emoji 完成。

### 让大模型帮你写脚本

系统提示词已经写好函数签名、入参和上面的限制。自己写脚本时，把这份提示词交给任意对话模型即可，DeepSeek、ChatGPT 或其他模型都可以。

1. 在标题或内容页签把改写引擎选成 **自定义脚本**。
2. 点 **复制系统提示词**。标题和内容各有一份，不要混用。
3. 打开一个新的对话，整段粘贴。
4. 在提示词后面追加你自己的规则，例如：

```
补充要求：
- 不要改原标题的文字、数量和词序
- 在标题开头随机插入一个表情，从 ✨、⭐、🔥、🎮 里选
- 在标题末尾随机插入一个字符，从 ★、♪、※ 里选
- 大约一半的情况，在标题中间再随机插入一个 ·
- 每次调用结果可以不同，总长度仍不超过 50
```

5. 让它「只输出可运行的 Python 源码」。提示词里已经要求不要 Markdown 代码围栏、不要解释。
6. 若回复仍包在 ` ```python ` 里，去掉围栏和说明，只保留源码。
7. 粘贴进脚本编辑器，点 **格式化**。
8. 用几条真实标题或档案描述做 **测试**。多测几次，确认随机结果都还保留核心信息。
9. 点 **保存**，再到任务编排里打开对应开关。

模型若生成了不允许的写法，测试会返回具体原因，例如「不允许导入 xxx」或「未定义函数 generate_title」。把报错原文贴回对话，让它按系统提示词重写，再测一次。

自己改脚本时也可以先点 **复制系统提示词**，对照限制检查。入口函数名必须是 `generate_title` 或 `generate_content`，改名后脚本不会被执行。

## 推荐接入顺序

1. 决定标题、内容各自用大模型还是脚本。
2. 用大模型时，先完成 API Key 的连接测试并保存。
3. 加载默认提示词或默认脚本，按品类改一版。
4. 用真实标题、真实描述快速测试。标题测试至少选一个有近期采集数据的游戏。
5. 保存 Deepseek 页。
6. 在目标账号的任务编排里选择「跟随全局设置」或「强制开启」。
7. 放行少量出品，在运行日志里确认出现标题或内容生成记录。标题失败时日志和编排状态会写明原因，并已关闭该子任务。

## 常见问题

**页面提示未配置 API Key，但我想用脚本。**  
把对应页签的改写引擎改成「自定义脚本」并保存。脚本路径不读取 Key。另一个页签如果仍是大模型，警告会继续出现，直到那个页签也改成脚本或补上 Key。

**测试成功，出品却没有改写。**  
先确认点过保存。再看该账号任务编排是「强制关闭」还是「跟随全局设置」。跟随全局时，Deepseek 页的开关必须是打开的。

**测试成功，出品标题优化后子任务被关掉。**  
出品比测试多了真实参考标题和平台字段。打开运行日志查看「标题生成失败」后面的原因，修脚本或 Key 后重新打开子任务。

**标题和参考标题仍然很像。**  
测试时要选择游戏，并确认近 30 分钟该分类有首页采集。提示词或脚本里写明「避开 others 中的标题」，同时仍然保留数量和型号。

**档案里看不到「Deepseek 优化描述」。**  
先在 Deepseek 的内容页签打开「档案内容优化」并保存，再重新进入商品档案的编辑表单。这个按钮只看全局开关，不看单个任务编排的强制开关。
